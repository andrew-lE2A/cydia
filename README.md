# Cydia

A public, multi-package static APT repository for jailbroken iOS packages.

## Add the source in Cydia

Open **Manage → Sources → Edit → Add** and enter:

https://andrew-le2a.github.io/cydia/

## Add or update a package

1. Put the package's .deb file in the debs/ folder.
2. Run python3 build-repo.py from the repository root.
3. Review Packages, Packages.gz, and Release generated by the script.
4. Commit the .deb and all three index files to the main branch.

The index includes every .deb in debs/, including older versions. Keep old package files so users can access prior versions. Package metadata and checksums are read from each .deb.

The repository is a flat static APT repo: Packages and Packages.gz are served at the repository root. GitHub Pages publishes the root of main.
